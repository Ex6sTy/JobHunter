# JobHunter

**JobHunter** – это инструмент для автоматического сбора и управления вакансиями с платформы hh.ru.

## Описание

Проект выполняет запросы к API hh.ru, получает данные о вакансиях и позволяет:
- Сохранять вакансии в JSON-файл.
- Добавлять новые вакансии.
- Фильтровать вакансии по ключевым словам и зарплате.
- Выводить топ N вакансий по зарплате.

Код написан с использованием принципов ООП и поддерживает расширение функциональности.

## Установка

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/Ex6sTy/JobHunter
   cd jobhunter
   ```

2. Убедитесь, что у вас установлен [Poetry](https://python-poetry.org/docs/):
   ```bash
   poetry --version
   ```

3. Установите зависимости:
   ```bash
   poetry install
   ```

4. Активируйте виртуальное окружение:
   ```bash
   poetry shell
   ```

## Использование

1. Для запуска программы выполните:
   ```bash
   python main.py
   ```

2. Следуйте инструкциям в консоли, чтобы:
   - Ввести поисковый запрос.
   - Задать количество выводимых вакансий.
   - Указать ключевые слова для фильтрации.

## Зависимости

- Python >= Python 3.13.0
- requests
- pytest (для тестов)
- black, flake8, isort (для линтинга и форматирования)

## Тестирование

Запустите тесты, чтобы убедиться в правильности работы функционала:
```bash
pytest
```
